**LocalPDF**: a sovereign PDF manipulation app for the DIP (Geneva).

## What it does

Import one or several PDFs, rearrange, rotate and delete pages, split the result into one or more PDFs, and download them. Everything happens in your browser.

- Import PDFs with a file picker or by drag and drop.
- Page grid with an adjustable size: select, rotate, delete, reorder by drag and drop, restore the initial state.
- Pages from several PDFs can be combined; a colour-coded legend shows which document each page comes from.
- One or several output PDFs, each with its own file name and page range (for example `1-3,5,7-9`; empty means all pages).
- Interface in French and English.

## Why "sovereign"

The tool is meant for teachers who need to manipulate PDFs without handing them to an online service. By design:

- **Local only**: PDFs are processed in the browser. No server, no account, no upload.
- **No third party**: no telemetry, no analytics, no CDN. The PDF libraries are vendored in `js/`.
- **Works offline**, from a local copy of the folder.
- **Readable**: plain HTML, CSS and JavaScript, no build step. The code that runs is the code you can read.
- Only interface preferences (language, a dismissed tip) are kept in the browser's `localStorage`.

These are design goals. The code review tracked in #2 is meant to confirm them.

## Use

Open `index.html` in a modern browser. There is nothing to install or build.
