# LocalPDF

LocalPDF is a small PDF tool that runs locally in your browser.

Open `index.html`, import PDFs, rearrange or rotate pages, split them into one or more outputs, and download the result. No server, no account, no upload.

## Why

- Files stay on your device.
- Works offline from the local folder.
- No backend or build step.
- Plain HTML, CSS and JavaScript.

## Use

Open `index.html` in a modern browser.

## Files

- `index.html`: app shell
- `app.js`: PDF workflow
- `i18n.js`: translations
- `styles.css`: UI
- `js/`: vendored PDF libraries
